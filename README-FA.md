# PEYKAN AI — نسخهٔ رایگان برای GitHub Pages

این پروژه یک وب‌سایت چت فارسی است که مدل زبانی را مستقیماً در مرورگر اجرا می‌کند. **هیچ API Key، سرور اختصاصی یا اشتراک پولی لازم نیست.** رابط کاربری و تاریخچهٔ گفتگوها روی GitHub Pages و مرورگر کاربر اجرا می‌شوند.

## امکانات

- اجرای مدل زبانی محلی در مرورگر با WebLLM و مدل `Qwen2.5-0.5B-Instruct-q4f16_1-MLC`
- تاریخچهٔ گفتگوها، ساخت چت جدید، تغییر گفتگو و حذف گفتگو
- ذخیرهٔ گفتگوها در `localStorage` مرورگر
- رابط فارسی راست‌چین و واکنش‌گرا
- نشانگر پیشرفت دانلود مدل و نمایش وضعیت
- کپی پاسخ‌ها
- بدون کلید API و بدون هزینهٔ سرویس API

## آنلاین کردن در GitHub Pages

1. فایل ZIP را از حالت فشرده خارج کن.
2. در GitHub یک مخزن جدید بساز؛ مثلاً `peykan-ai`.
3. فایل‌های `index.html`، `style.css`، `script.js` و `README-FA.md` را در ریشهٔ مخزن آپلود کن. پوشهٔ `assets` اختیاری است و می‌توانی آن را هم آپلود کنی.
4. وارد **Settings → Pages** شو.
5. در **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کن.
6. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و Save کن.
7. پس از چند دقیقه آدرس سایت در همان بخش Pages نمایش داده می‌شود.

## اولین اجرا

- با نسخهٔ به‌روز Chrome یا Edge و سخت‌افزاری که WebGPU را پشتیبانی می‌کند باز کن.
- روی وضعیت مدل در بالای صفحه بزن و «بارگذاری مدل رایگان» را انتخاب کن.
- دانلود اولیه می‌تواند چندصد مگابایت باشد. تا پایان دانلود، صفحه را نبند.
- پس از دانلود، مرورگر ممکن است فایل‌های مدل را برای اجراهای بعدی نگه دارد؛ رفتار حافظهٔ نهان به مرورگر بستگی دارد.

## محدودیت‌ها

- اجرای مدل به پشتیبانی WebGPU، حافظهٔ آزاد و توان دستگاه بستگی دارد. روی بعضی دستگاه‌ها ممکن است کند باشد یا اصلاً اجرا نشود.
- مدل کوچک است؛ پاسخ‌هایش ممکن است از سرویس‌های ابری قوی‌تر ضعیف‌تر یا نادقیق‌تر باشند.
- این مدل اطلاعات زنده و جست‌وجوی اینترنتی داخلی ندارد.
- تاریخچه فقط در همان مرورگر و همان دستگاه ذخیره می‌شود. پاک‌کردن داده‌های سایت یا استفاده از مرورگر دیگر می‌تواند آن را از دسترس خارج کند.
- برای بارگیری کتابخانه و مدل، اتصال اینترنت لازم است. این پروژه برای تولید پاسخ به سرویس API پولی متصل نمی‌شود.
- وابستگی WebLLM از CDN و وزن‌های مدل از زیرساخت میزبانی مدل دریافت می‌شوند؛ در صورت تغییر یا قطع سرویس بیرونی، بارگذاری ممکن است از کار بیفتد.

## حریم خصوصی

پیام‌ها برای تولید پاسخ به مدل محلی مرورگر داده می‌شوند و در کد این پروژه به سرور شخصی ارسال نمی‌شوند. با این حال، کتابخانه و فایل‌های مدل از CDN و میزبان مدل دریافت می‌شوند؛ این پروژه به معنی تضمین ناشناس‌بودن همهٔ درخواست‌های شبکه نیست.
